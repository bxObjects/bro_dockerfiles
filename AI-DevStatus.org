* Architecture

** Directory hierarchy

#+BEGIN_SRC

debian/
  <majorRelease>/                  12 or 13; ftoBranchProc.spcs (13: ordered branches)
    confined/vnc/xfce/             unprivileged, entrypoint.sh init
      bisos_debNN-fresh/
    privileged/vnc/xfce/           --privileged (docker), systemd PID 1
      bisos_debNN-sysd/
      bisos_deb13-sysd-2/          secondary instance: runs bisos_deb13-sysd's image
    rootless-sysd/vnc/xfce/        rootless podman, systemd PID 1 (cgroup v2)
      bisos_debNN-rootless-sysd/
PriorAndSimilarArt.org  figures/
#+END_SRC

The path is configuration for the =.spcs= way: =debian/<release>/<profile>/vnc/xfce/<leafName>/=
→ distro, release, profile (engine/privilege/init), desktop, image name. Container name, host ports
and (cgroup v1) subnet are read from the leaf's compose / Quadlet file by *both* ways.

*Numeric-suffix rule (user):* leaf =<primary>-<N>= is instance N of =../<primary>='s image; only
the primary builds it. Its compose files have =image: <primary>:latest= and no =build:=.

* Key Design Decisions

- *init/isolation profile as the hierarchy dimension* --- three peers named by property
  (=confined=, =privileged=, =rootless-sysd=), not by tool (docker/podman).
- *rootless-sysd collapses the confined/privileged tradeoff* --- systemd PID 1 with an
  unprivileged posture, via rootless Podman. Requires cgroup v2.
- *Privileged/rootless images layer on confined* --- =FROM bisos_debNN-fresh:latest=, so package
  updates flow through on rebuild.
- *VNC/noVNC/sshd as systemd units* in the sysd images.
- *bystar home dir 755*; *tmp-exec.service oneshot* (Docker's =tmpfs:= mounts =/tmp= =noexec=;
  remounted exec at boot); *=/dev/shm= 2G* (=dev-shm-resize.service=, see the Blee panel).
- *cgroup: host (v2)*; *cgroup-v1 overlay* (=docker-compose.cgv1.yml=: no =cgroup: host=,
  =/sys/fs/cgroup:ro= + =/sys/fs/cgroup/systemd:rw=).
- *Explicit cgroup v1 subnet per leaf, in =172.16.0.0/16=* (was =10.254.x=, moved after on-host
  verification) --- avoids "all predefined address pools have been fully subnetted";
  =containerManage.sh create= refuses an overlap with a docker network or host route. Allocation
  by a registrar is =bisos.dockerProc= Stage 4.
- *USER root in sysd Dockerfiles*; *polkit masked*; *=--isolation=chroot= for rootless builds*;
  *verify.sh exec-free*; *graphroot on a large local disk*.
- *Keep =cgroup_manager = systemd= at RUNTIME (rootless-sysd)* --- =cgroupfs= was tried and the
  container fails to boot. =podmanHostVerify.cs='s =--cgroup-manager=cgroupfs= advice applies to
  *build* only; the runtime fix for a missing session is a real login session plus
  =loginctl enable-linger=.
- *Debian 12 vs 13 host (rootless-sysd)* --- Podman 4.3.1 needs chroot isolation + exec-free
  verify; 5.4.2 fixes both. Debian 13 is the primary rootless target.
- *Two permanent ways, at parity (2026-10-26, user)* --- standalone needs no BISOS and is the
  only way on the old RedHat VMs; the repo does not depend on =bisos.dockerProc=. A change to one
  way is mirrored into the other.
- *Scripts byte-identical in every leaf, everything derived (2026-10-26, user)* --- image = leaf
  name, engine from the profile, base from =FROM=, container name / ports / subnet from the
  compose or Quadlet file (the single source), hub name from the Dockerfile =LABEL=.
- *=create= only creates*; =start= is separate (the BISOS =instanceUp= does both). =create=
  checks first and changes nothing on any problem; never builds.
- *Numeric suffix = shared image* (=<primary>-<N>=).
- *No VNC password is the default; a password is a state* (non-empty
  =/home/bystar/.config/bisosVncPasswd=), set by =cp= (not =exec=), lost on =delete=. Classic VNC
  auth: 8 characters, no encryption --- use an SSH tunnel over a network.
- *Gate and status files are per VM, never pushed* --- one user per VM, each with their own clone.
- *Raw-BISOS payload copied (=cp=), not symlinked*, from =common/raw-bisos/=.
- *Path as configuration for the =.spcs= way* --- consistent with the BISOS spcs pattern.
