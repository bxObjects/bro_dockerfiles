** Confined images (=bisos_deb{12,13}-fresh=)

- Base: =debian:12.12= / =debian:13.1= built from scratch
- Init: =dockerConf/entrypoint.sh= starts sshd, VNC, noVNC directly; =sleep infinity= keeps container alive
- VNC xstartup: =dockerConf/xstartup= launches =startxfce4=
- User: =bystar= created via =useradd= with =chmod 755 /home/bystar= (useradd default is 700)
- Volume: =./= mounted at =/shuttle/this=; =raw-bisos/= mounted at =$HOME/raw-bisos= at runtime
- Ports (host): SSH=2222, VNC=5901, noVNC=6901

** Privileged images (=bisos_deb{12,13}-sysd=)

- Base: =FROM bisos/deb12-fresh-vnc-xfce:1.21= (or deb13 equivalent) — layers on confined
- =USER root= immediately after FROM (base ends as =USER bystar=; systemd + build steps need root)
- Init: =/sbin/init= (systemd PID 1); =STOPSIGNAL SIGRTMIN+3=
- Services: =vncserver.service=, =novnc.service=, =sshd-container.service=, =tmp-exec.service= installed and enabled
- =tmp-exec.service=: oneshot that runs =mount -o remount,exec /tmp= early in boot;
  needed because Docker's tmpfs mounts apply =noexec= by default
- Suppressed units: udev, getty, plymouth, rescue, initctl
- Masked: =polkit.service= (fails in containers, would leave systemd =degraded=)
- docker-compose.yml (v2 host): =privileged: true=, =cgroup: host=, =/sys/fs/cgroup= rw,
  =/sys/fs/fuse=, tmpfs on =/tmp /run /run/lock /var/log/journal=
- docker-compose.cgv1.yml (v1 host): =privileged: true=, NO =cgroup: host=,
  =/sys/fs/cgroup:ro= + =/sys/fs/cgroup/systemd:rw=, container_name suffixed =-cgv1=;
  includes explicit =networks:= block with =subnet: 10.254.13.0/24= (deb13) to handle
  hosts where Docker's default bridge pool is exhausted
- =build.bash=: supports =-d= (local build) and =-n= (=--no-cache=)
- Ports (host): deb12 SSH=2223 VNC=5902 noVNC=6902; deb13 SSH=2224 VNC=5903 noVNC=6903

** Rootless-sysd images (=bisos_deb{12,13}-rootless-sysd=)

- Build identical to privileged sysd (FROM confined + =USER root=, systemd, unit
  suppression, enabled services, ENTRYPOINT =/sbin/init=). Difference is run-time only.
- Run: =run.bash= → =podman run --systemd=always=, NO =--privileged=, NO
  =/sys/fs/cgroup= mount, NO cgroupns. Podman does cgroup delegation + tmpfs itself.
- Per-engineer multi-tenant form: Quadlet =*.container= unit (=systemctl --user=
  + =loginctl enable-linger=).
- =build.bash=: uses =--isolation=chroot= for all podman builds; auto-builds confined
  base if missing in Podman's store.
- =verify.sh=: exec-free (SSH-based); =degraded= is WARN not FAIL.
- Ports (host): deb12 SSH=2225 VNC=5904 noVNC=6904; deb13 SSH=2226 VNC=5905 noVNC=6905
- Requires: rootless Podman + crun + cgroup v2 with controller delegation.
  Does NOT work on cgroup v1.

* Key Design Decisions

- *init/isolation profile as the hierarchy dimension* — three peers named by
  property (=confined=, =privileged=, =rootless-sysd=), not by tool (docker/podman).

- *rootless-sysd collapses the confined/privileged tradeoff* — systemd PID 1
  with unprivileged posture, via rootless Podman. Requires cgroup v2.

- *Privileged/rootless images layer on confined* — =FROM bisos/deb{12,13}-fresh-vnc-xfce=
  so package updates flow through on rebuild; no duplication of apt-get installs.

- *VNC/noVNC/sshd as systemd units* — restart-on-failure, dependency ordering,
  =systemctl status= visibility. Replaces manual =entrypoint.sh= approach.

- *bystar home dir 755* — =useradd= default is 700; =chmod 755= added to confined
  Dockerfiles. Privileged/rootless inherit via FROM.

- *tmp-exec.service oneshot* — Docker's =tmpfs:= shorthand applies =noexec= by
  default. A systemd oneshot running =mount -o remount,exec /tmp= at boot corrects
  this to match Debian's default. Simpler alternatives (compose long-form tmpfs,
  tmp.mount.d drop-in) do not work because Docker mounts /tmp before systemd starts.

- *cgroup: host (v2)* — correct Compose key (maps to =--cgroupns=host=); the
  invalid =cgroupns: host= key was used originally and rejected by the schema.

- *cgroup-v1 overlay* — =docker-compose.cgv1.yml= drops =cgroup: host= and uses
  classic v1 recipe (=/sys/fs/cgroup:ro= + =/sys/fs/cgroup/systemd:rw=).

- *Explicit subnet in cgv1 compose* — shared hosts exhaust Docker's default bridge
  pool (172.17--172.31, 192.168/16). Explicit =subnet: 10.254.13.0/24= sidesteps
  "all predefined address pools have been fully subnetted". Adjust per host.

- *build.bash -n for --no-cache* — Docker layer cache can serve stale layers after
  Dockerfile changes if intermediate layers are unchanged. =-n= forces a clean build.

- *USER root in sysd Dockerfiles* — confined base ends as =USER bystar=; privileged
  Dockerfiles need =USER root= right after =FROM= for apt/systemctl build steps.

- *polkit masked* — fails in containers (no seat/active session), leaves systemd
  =degraded=. Masked in all four sysd Dockerfiles.

- *--isolation=chroot for rootless builds (old Podman)* — Podman 4.3.1 buildah
  sd-bus failure workaround. Harmless on newer Podman; kept for portability.

- *verify.sh exec-free (rootless-sysd)* — =podman exec= broken on old Podman for
  systemd containers. Uses host ports + noVNC HTTP + SSH session instead.

- *graphroot on large local disk* — rootless Podman store must not be on near-full
  or NFS filesystem. Set via =~/.config/containers/storage.conf=.

- *Debian 12 vs 13 host (rootless-sysd)* — Podman 4.3.1 (Debian 12) needs chroot
  isolation + exec-free verify. Podman 5.4.2 (Debian 13) fixes both.
